News & Updates
Material Paths
One per line. Copy them from the Files tab, or paste any material path. Niagara systems go in the Particle Converter button above.
The converter starts its own API in the background. The first start reads the game files and can take a minute. Each converted shader is saved in its own folder inside Shader Conversions, and everything it pulled in is filed under Cache with the same name.
Niagara System Paths
One per line. Copy them from the Files tab, or paste any Niagara system path (NS_...).
Niagara systems are converted on their own, separate from the Shader Converter. Each one is saved in its own folder inside Particle Conversions, with the materials and meshes it uses.
Blueprint Paths
Sky domes and props with lights, sounds and particle systems. One per line. Copy them from the Files tab, or paste any Blueprint path (BP_...).
Each Blueprint is saved in its own folder inside Blueprint Conversions, with its shaders, textures, meshes and day cycle. Copy the whole Blueprint Conversions folder into your Unity project's Assets and Unity builds the prefab by itself.
